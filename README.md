# Calculadora de Pity Gacha

Ferramenta gratuita e de código aberto para calcular suas chances em jogos gacha (Genshin Impact, Honkai Star Rail, Zenless Zone Zero e outros).

**Demo online:** https://gachanebula-br.github.io/gachanebula-tools/

## O que ela faz

- Calcula a chance de conseguir o personagem 5★ em destaque com os pulls que você tem
- Considera o pity atual, o soft pity, o hard pity e o 50/50 (ou 75/25)
- Mostra quantos pulls você deve precisar em média, e para chegar a 50% e 90% de chance
- Desenha um gráfico da probabilidade acumulada
- Já vem com predefinições para jogos populares

## Como usar

1. Use online pelo link da demo acima, ou baixe o arquivo `index.html`
2. Abra no navegador (Chrome, Firefox, Edge). Não precisa de internet nem de instalação
3. Escolha uma predefinição ou preencha os valores do seu jogo
4. Informe seu pity atual e quantos pulls você tem

## Observações

O modelo é simplificado: a chance sobe de forma linear do soft pity até o hard pity. Os números reais podem variar de jogo para jogo, então use como estimativa.
